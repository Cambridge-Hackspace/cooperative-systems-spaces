Debug Admin Access

Open your browser's developer console (F12) and paste this JavaScript to debug your admin access:

// Check your current authentication status const authStore = JSON.parse(localStorage.getItem('css_token') || 'null'); console.log('Auth Token:', authStore); // Make a request to check your current user fetch('/api/auth/me', { headers: { 'Authorization': 'Bearer ' + authStore, 'Content-Type': 'application/json' } }) .then(response => response.json()) .then(data => { console.log('Current User:', data); if (data.success && data.data) { console.log('User Role:', data.data.role); console.log('Is Admin?', data.data.role === 'admin'); console.log('Role Type:', typeof data.data.role); } }) .catch(error => console.error('Error:', error));

This will help us see what role your user actually has and debug the admin access issue.
